Recommended install (with uv)

# Base installation
uv add django-control-components

# Optional extras:
uv add "django-control-components[wizard]"  # Multi-step forms (django-formtools)
uv add "django-control-components[images]"  # Image upload & Pillow processing

# Everything at once:
uv add "django-control-components[wizard,images]"

Or with pip: pip install "django-control-components[wizard,images]"

Settings

INSTALLED_APPS = [
    # ...
    "django_cotton",  # must precede django_control_components
    "django_control_components",
]

Assets

Add {% templatetag openblock %} dcc_assets {% templatetag closeblock %} to your base template <head> - it emits the stylesheet, htmx, Alpine, the focus plugin, and the Font Awesome icon stylesheet, in that order:

<head>
  {% templatetag openblock %} load dcc_tags {% templatetag closeblock %}
  {% templatetag openblock %} dcc_assets {% templatetag closeblock %}
</head>

If your project already loads Alpine, pass alpine=False so it is not loaded twice: {% templatetag openblock %} dcc_assets alpine=False {% templatetag closeblock %}. See deployment for CSRF, static files and CSP.

Pinned client dependencies

  • Font Awesome 6.7.2 Free
  • htmx 2.0.4 - mutations, table fragments, wizard steps
  • Alpine.js 3.17.1 (+ @alpinejs/focus for modal / drawer focus traps)

Theming

Components emit semantic dcc-* classes and design tokens as CSS custom properties. Override them in your own stylesheet, loaded after {% templatetag openblock %} dcc_assets {% templatetag closeblock %}:

:root {
  --dcc-primary: #4f46e5;
  --dcc-radius: 0.5rem;
  --dcc-font: Inter, system-ui, sans-serif;
}

Or point a Tailwind v4 build at css/dcc.css to tree-shake and re-theme.
