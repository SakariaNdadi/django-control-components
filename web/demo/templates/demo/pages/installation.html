Installation & Setup

Studio: dev-only prototyping ([studio] extra)

Filament-inspired schema, table, and action builders for Django. Declare UI in Python; it renders itself through django-cotton, wired to real django.forms validation.

Recommended Install (with uv)

# Base installation
uv add django-control-components

# Optional extras:
uv add "django-control-components[wizard]"  # Multi-step forms (django-formtools)
uv add "django-control-components[images]"  # Image upload & Pillow processing

# Install everything at once:
uv add "django-control-components[wizard,images]"

Or using standard pip: pip install "django-control-components[wizard,images]"

Settings Configuration

INSTALLED_APPS = [
    # ...
    "django_cotton",  # must precede django_control_components
    "django_control_components",
]

Asset Loading

Add {% templatetag openblock %} dcc_assets {% templatetag closeblock %} to your base template <head> - it emits the stylesheet, htmx, Alpine, the focus plugin, and Font Awesome icons automatically:

<head>
  {% templatetag openblock %} load dcc_tags {% templatetag closeblock %}
  {% templatetag openblock %} dcc_assets {% templatetag closeblock %}
</head>

Pinned Client Dependencies

  • Font Awesome: v6.7.2 Free (Solid, Regular, Brands, Duotone)
  • htmx: v2.0.4 (transparent partial DOM updating & step navigation)
  • Alpine.js: v3.17.1 (+ @alpinejs/focus v3.17.1 for modal trap)

Preventing Duplicate Alpine Instances

If your project already includes Alpine.js globally, pass alpine=False to prevent duplicate instances and conflicts:

{% templatetag openblock %} dcc_assets alpine=False {% templatetag closeblock %}

DCC's components (dccTable, dccForm, dccChart, dccSelect, etc.) rely on Alpine's reactive directives (x-data, x-model, x-show, Alpine.data()) for instantaneous in-page UI state alongside htmx mutations.

Customizing & Overriding CSS

The library provides semantic tokens as CSS custom properties. You can customize styling globally, per-component, or via Tailwind CSS v4:

1. Global Design Tokens

/* static/css/theme.css */
:root {
  --dcc-primary: #0284c7;        /* Sky blue primary buttons / active nav */
  --dcc-primary-fg: #ffffff;     /* Button text */
  --dcc-radius: 0.75rem;         /* Rounded corners */
  --dcc-font: "Inter", system-ui, sans-serif;
  --dcc-gap: 1.25rem;
  --dcc-bg: #f8fafc;
  --dcc-surface: #ffffff;
  --dcc-border: #e2e8f0;
  --dcc-success: #10b981;
  --dcc-danger: #ef4444;
}

@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) {
    --dcc-bg: #0f172a;
    --dcc-surface: #1e293b;
    --dcc-border: #334155;
    --dcc-primary: #38bdf8;
    --dcc-primary-fg: #0f172a;
  }
}

2. Scoped Per-Component Overrides

Target a specific wizard view with wizard_attrs:

class CheckoutWizard(WizardView):
    wizard_class = "custom-checkout-card"
    wizard_attrs = {
        "style": "--dcc-wizard-bg: #f8fafc; --dcc-wizard-accent: #10b981; --dcc-wizard-radius: 1rem;"
    }

Or wrap tables and cards inside scoped containers:

<div class="my-custom-table-wrapper">
  {{ table_html }}
</div>

<style>
  .my-custom-table-wrapper {
    --dcc-radius: 0.5rem;
    --dcc-border: #cbd5e1;
  }
  .my-custom-table-wrapper .dcc-table tbody tr:hover {
    background-color: #f1f5f9;
  }
</style>

3. Tailwind CSS v4 Purging

Point @tailwindcss/cli at css/dcc.css to compile and purge:

/* src/my-app.css */
@import "tailwindcss";
@source "../templates";
@source "../src/django_control_components/templates";

@theme {
  --color-dcc-primary: #6366f1;
  --radius-dcc: 0.5rem;
}
npx @tailwindcss/cli -i src/my-app.css -o static/dist/app.min.css
