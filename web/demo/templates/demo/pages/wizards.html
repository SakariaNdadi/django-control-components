Installation

Wizards rely on django-formtools for secure session storage and state handling:

uv add "django-control-components[wizard]"

How Wizards Work

WizardView inherits from SessionWizardView. Instead of full page reloads, each step submit posts over htmx and replaces only the wizard container (#dcc-wizard-*). If JavaScript is disabled, normal full-page POSTs work out of the box.

Complete Runnable View Example

from django.shortcuts import redirect
from django_control_components.wizards import WizardView, WizardStep
from django_control_components.schemas import Schema, TextInput, Select, Toggle
from django_control_components.infolists import Infolist, TextEntry
from myapp.forms import DetailsForm, SettingsForm
from myapp.models import Project

class ProjectCreateWizard(WizardView):
    # Optional styling hooks
    wizard_class = "project-wizard"
    show_step_nav = True

    steps_config = [
        # Step 1: Form step with Schema
        WizardStep(
            "details",
            Schema.make()
            .form(DetailsForm)
            .strict()
            .schema([
                TextInput.make("name").required(),
                TextInput.make("description"),
            ]),
            title="Details",
            heading="Project Basics",
            description="Enter project name and general summary.",
        ),
        # Step 2: Second form step
        WizardStep(
            "settings",
            Schema.make()
            .form(SettingsForm)
            .strict()
            .schema([
                Select.make("tier").options([("free", "Free"), ("pro", "Pro")]),
                Toggle.make("is_public"),
            ]),
            title="Settings",
            heading="Configuration",
        ),
        # Step 3: Review / Confirmation step using Infolist
        WizardStep(
            "review",
            Infolist.make().schema([
                TextEntry.make("name").label("Project Name"),
                TextEntry.make("tier").label("Selected Plan"),
                TextEntry.make("is_public").label("Public Access"),
            ]),
            title="Review",
            heading="Review & Confirm",
            description="Verify the project details before creating.",
            record=lambda view: view.get_all_cleaned_data(),
        ),
    ]

    def done(self, form_list, **kwargs):
        # Automatically gathered from all step forms:
        data = self.get_all_cleaned_data()
        project = Project.objects.create(**data)
        return redirect("project-detail", pk=project.pk)

Customizing Appearance

Customize wizard styles using CSS custom properties via wizard_attrs:

class CustomWizard(WizardView):
    wizard_attrs = {
        "style": "--dcc-wizard-accent: #4f46e5; --dcc-wizard-radius: 0.75rem;"
    }
